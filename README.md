# Paradise Nursery

## Project Name
Paradise Nursery

## Description
Paradise Nursery is a plant shopping web application built using React. 
It allows users to browse different plants, add plants to a shopping cart,
remove items, and update the quantity of items in the cart.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Redux Toolkit
- Vite

## Features
- Paradise Nursery landing page
- About Us section
- Plant product listing
- Add plants to cart
- Remove plants from cart
- Update product quantity
- Shopping cart
- Responsive user interface
